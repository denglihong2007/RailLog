# 对比每周成就.xlsx 的固定噪声

*迁移自 Claude Code 项目记忆 · 更新于 2026-10-24*

桌面上的 `26w45成就.xlsx`（每周更新的成就规格草稿）与 `api/Services/AchievementEngine.cs` 比对时，有几处固定噪声，不要当成真实差异：

1. **数字排版**：Excel 写 `至少24小时`、`1000km`，引擎统一为 `至少 24 小时`、`1,000 公里`（阿拉伯数字前后加空格、千分位、km→公里）。近 90 条"取得条件不一致"里九成都是这一类。

2. **附表编号（26w45 现行）**：`附表1`=长江大桥、`附表2`=黄河大桥、`附表3`=跨海大桥、`附表4`=隧道、`附表5`=省会/首府/直辖市/香港**车站表**、`附表6`=和谐号/复兴号**车组表**。
   Excel 自身的交叉引用仍有两处旧编号笔误：「功盖振声」写"详见附表4"（应是附表5）、「百车全书」写"详见附表5"（应是附表6）；「百花丛中」的附表6 是对的。引擎里的 Note 编号是正确的，**别照 Excel 改回去**。
   26w42 及以前的旧编号（附表4=车组）已不再适用。

3. **附表6 的「数量」列不可信**：Excel 有 9 个型号的数量单元格与同一行的车号区间对不上（CRH2G、CRH3A-A、CRH6A-A、CRH380A、CRH380B、CR400AF、CR400AF-A、CR400BF-Z、CR400BF-GS）。以区间为准；引擎的 65 个型号区间与 Excel 完全一致。Excel 共 69 行、去重后 65 个型号（多出的几行是重复/表头）。

4. **附表1 的旧站名**：Excel 仍写「宜昌东-宜昌南」「枝江-枝城」，新线路库里没有宜昌南、枝江；引擎用的是「宜昌东-长阳」「鸦雀岭-枝城」，可解析且覆盖同一座桥。「天兴洲」Excel 写「滠口-武汉」，引擎另写「滠口-楠姆庙所」（楠姆庙所在桥南端），两者都跨桥。

5. **表头行**：成就 sheet 的第 5 行（隐藏成就是第 4 行）是 `成就标题 | 经验 | 取得条件 | 注释 | 技术性说明`，分类名（历程丰碑/极限挑战/铁道图鉴/巡游四方/趣味旅程）单独占一行只有 B 列。按"B、C 两列都有值"筛条目时记得剔除表头，否则会多出 1 条/表。

6. **茕茕孑立的取得条件笔误**：Excel 写 `乘坐一次RZ25K-111111车厢…`，客车车号其实只认空格分隔（正确是 `RZ25K 111111`），引擎已按正确写法收录，diff 会报这一条"取得条件不一致"——是**有意为之**，别改回去。详见 [train-model-parser-number-forms](./train-model-parser-number-forms.md)。

经验值列的 `80+`、`50+` 表示"有额外加成"，对应定义里的 `MaxExperience`，不是数值不一致。另外「永磁动力」的技术性说明列在 26w45 里明显是从「宫车之过」复制过来的（列的是 LKJ 车组、上限 50，和它自己的 CRH380AN 条件/经验格矛盾），遇到时先向作者确认，不要直接实现。

**Why:** 每次"对比 Excel"都会重新踩一遍，白花十几分钟。
**How to apply:** 直接按"名称 → 经验/取得条件"做全量 diff，然后只人工看上面几类以外的条目。相关：[achievement-icon-contract](./achievement-icon-contract.md)
