# 设置页副标题的写法

*迁移自 Claude Code 项目记忆 · 更新于 2026-10-10*

RailLog 设置页每一行的副标题只描述设置项本身，不呈现当前值/状态。例如写「主题、底图显示层级与行程详情」，而不是「跟随系统 · 湖蓝」；写「云同步开关与 Excel 导入导出」，而不是「自动同步已开启」。

**Why:** 用户明确要求（2026-10-10）。状态式副标题还逼着每一行去订阅对应 service、或在首帧异步读盘，根页面因此变重、还会闪一下「正在读取配置」。

**How to apply:** 新增设置入口行时，用一句话概括该页里有什么；确实需要展示当前值就放进子页面里。相关：[widget-tests-cannot-do-io](./widget-tests-cannot-do-io.md)
