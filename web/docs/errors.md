# 格式与错误

## HTTP 状态码

| 状态码 | 说明 |
| --- | --- |
| `200` | 请求成功。搜索不到车次通常返回空数组。 |
| `400` | 参数缺失、为空或超出支持范围；正文通常为 `{ "message": "..." }`。 |
| `404` | 指定行程或用户不存在。 |
| `5xx` | 服务暂时不可用；调用方应采用指数退避重试。 |

时刻表接口的 `version` 格式不是 `yyyy.MM.dd`，或不在 `/api/train-timetables/versions` 返回的列表中时，返回 `400`。

## 格式约定

除时刻表停站和搜索项为兼容铁路数据源使用蛇形命名外，JSON 字段使用 `camelCase`。时间为 ISO 8601 字符串；可选值可能为 `null`。所有响应采用 UTF-8。

## 问题反馈

发现接口问题、需要订阅变更，或想报告文档与实际行为不一致时，请到 [GitHub Issues](https://github.com/denglihong2007/RailLog/issues) 反馈。
